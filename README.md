# USTB-RANK

北京科技大学「本研一体化教务管理系统」（byyt.ustb.edu.cn）成绩查询页增强脚本：显示**每门课的课程排名**和**"通过"课的真实分数**。

> 大学按选课教学班上课（不是行政班级），这里的排名指**同一门课全体选课学生（跨教学班合并）**中该门课总评成绩的排名；军训等全校课程即为全年级排名。数据是学校成绩接口本来就返回给你本人、只是界面上没有渲染的原始字段。

## 功能

- 每门课「总评成绩」分数正下方显示小字 **`排名 x/y 前 z%`**（无需横向滚动表格）；
- 表格最右追加「课堂排名」「真实成绩」两列（表格较宽，需向右滚动）；
- 界面显示"通过/合格"的课程显示实际百分制分数（蓝色加粗）；
- 页面刷新、翻页、切换学期筛选后 1 秒内自动补回；接口失败时右下角弹红色提示。

## 安装（Tampermonkey）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 打开本仓库的 `USTB-RANK.js`，复制全部内容，粘贴到 Tampermonkey「添加新脚本」编辑器中保存；
3. 登录教务系统，打开「个人成绩查询」页（主页点「成绩」，或直达 `https://byyt.ustb.edu.cn/cjgl/grcjcx/go/1`）自动生效。

## 数据来源与口径

| 显示内容 | 接口字段 | 说明 |
|---|---|---|
| 课程排名 | `pm` / `zrs` | 该门课程全体选课学生中的总评排名 / 参与排名总人数（跨教学班合并计算；军训等全校课即全年级人数） |
| 真实成绩 | `zzzscj` | "通过/合格"背后的百分制实际分数 |
| 百分位 | 计算值 | `pm ÷ zrs × 100%`，即"前 x%" |

## 免责声明
